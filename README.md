# LearnMate Engineering - Placement Preparation Platform

A comprehensive React-based platform designed specifically for **Engineering Students** (BTech, BE, BCA, etc.) to prepare for placements and develop technical skills.

## 🎯 **Target Audience**
- **BTech/BE Students** (All branches)
- **BCA/MCA Students**
- **Engineering Students** preparing for placements
- **Students** wanting to develop technical skills

## ✨ **Key Features**

### 🎓 **Engineering-Focused Onboarding**
- Comprehensive registration for engineering students
- Degree, branch, and year selection
- Tech stack preferences (JavaScript, Python, Java, React, etc.)
- Career goal targeting (SDE, Full Stack, ML Engineer, etc.)
- Target placement year setting

## 🚀 **Getting Started**

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. **Clone or navigate to the project directory:**
   ```bash
   cd Mkcummins_competition
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```

4. **Open your browser and visit:**
   ```
   http://localhost:3000
   ```

### Building for Production
```bash
npm run build
```
